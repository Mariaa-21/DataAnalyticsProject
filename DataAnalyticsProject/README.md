# Data Analytics Task

## Tasks Completed
- Web Scraping
- Exploratory Data Analysis (EDA)
- Sentiment Analysis

## Technologies Used
- Python
- Pandas
- BeautifulSoup
- Matplotlib
- Seaborn
- TextBlob

## Project Description
This project collects book data from a website using web scraping techniques, performs exploratory data analysis on the dataset, and analyzes sentiments using NLP techniques.

## Files
- scraper.py → Web scraping
- eda.py → Data analysis and visualization
- sentiment.py → Sentiment analysis
- books.csv → Scraped dataset
